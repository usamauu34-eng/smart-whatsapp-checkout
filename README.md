# Smart WhatsApp Checkout & Recovery Engine for WooCommerce

ایک جدید، تجارتی درجے کا ورڈپریس ووکامرس پلگ اِن جو کارٹ کے ترک ہونے کے مسئلے (Cart Abandonment) کو حل کرتا ہے اور صارفین کو ون کلک واٹس ایپ آرڈر پلیسمنٹ کی سہولت دیتا ہے۔

## اہم خصوصیات (Key Features)

- **خودکار ووکامرس آرڈر تخلیق (Automated Pending Orders):**  
  کسٹمر کے واٹس ایپ بٹن دبانے پر بیک گراؤنڈ میں AJAX کے ذریعے ایک باقاعدہ ووکامرس پینڈنگ آرڈر بنتا ہے، جس سے انوینٹری خودکار اپڈیٹ رہتی ہے۔
- **ڈائنامک میسج پے لوڈ (Dynamic Payload Generation):**  
  پروڈکٹ کا نام، مقدار، ویرینٹ اور کل قیمت خود بخود منظم فارمیٹ میں واٹس ایپ میسج کا حصہ بنتی ہے۔
- **اینالیٹکس و لیڈ لاگز ڈیش بورڈ (Real-Time Lead Tracking):**  
  ایڈمن پینل میں واٹس ایپ کے ذریعے آنے والے کل آرڈرز، متوقع آمدن اور حالیہ آرڈر لاگز کا تفصیلی لائیو ڈیش بورڈ۔
- **گلوبل پلسنگ فلوٹنگ وزٹ (Floating Sticky Widget with Pulse Animation):**  
  سائٹ کے تمام صفحات پر فوری رابطے کے لیے جدید سی ایس ایس پلس اینیمیشن کا حامل فلوٹنگ بٹن۔
- **ماڈیولر او او پی ساخت (Modular OOP Architecture):**  
  ایڈمن، پبلک اور آرڈر ہینڈلر کی الگ الگ کلاسز جو ورڈپریس کے کوڈنگ معیارات کے مطابق ہیں۔
